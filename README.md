# Hamida Sultana — Personal Portfolio

A responsive personal portfolio built with HTML and Tailwind CSS v4.

## Run locally

1. Open this folder in VS Code.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and keep the terminal running.
5. Open `index.html` with VS Code Live Server, or open it in a browser.

For a production CSS file, run `npm run build`.

## Before submitting

- Replace `Add your email address` with your professional email.
- Replace `YOUR_EMAIL@example.com` in the contact form action with the same email.
- Add your real GitHub and LinkedIn profile URLs.
- Add your institution name if you want to display it.
- Replace the illustrated avatar with your own photo if preferred.
- Replace practice project descriptions/previews with your actual work as you complete more projects.

## Important notes

- The three project cards are clearly labelled as practice concepts; they are not claims of completed client projects.
- The contact form is a front-end demo using `mailto:`. It does not store or send messages through a backend.
- Live Demo and Source Code links are not shown until real project URLs are available.
